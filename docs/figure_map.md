## Dependency order

Figure S1 is the only script with prerequisites. It plots the simulated values from Figure 3
panel A against theory, with error bars that come from an independent replication:

```
figure3_figure4_heatmaps.py ──→ arrays/Fig3_scenario1_highh_A.npy ─┐
                                                                   ├──→ figureS1_theory_vs_simulation.py
replicate_figure3A_panel.py ──→ tables/replication_fig3A_panel.npz ┘
```

Everything else is independent. `make figures` runs them in the right order.

## Supporting scripts

| Script | Purpose | Output |
|---|---|---|
| `replicate_figure3A_column.py` | Per-cell standard errors and z-scores for one column; also checks the closed-form R² identity against an explicit least-squares fit | `tables/replication_fig3A_column_hh2_0.6.csv` |
| `replicate_figure3A_panel.py` | The same across the full grid; supplies Figure S1's error bands | `tables/replication_fig3A_panel.npz` |
| `verify_reproducibility.py` | Compares regenerated arrays against `reference/arrays/` | console report, exit status |

## Reference arrays

`reference/arrays/` holds the eight arrays behind the published heatmaps (about 1.6 KB each).
They are committed so that anyone can verify a reproduction without first having to trust a
re-run, and so that a change in behaviour is caught rather than silently absorbed.
