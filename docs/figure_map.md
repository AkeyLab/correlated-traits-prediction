`render_heatmaps.py` redraws Figures 3, 4, S1 and S2 from the saved arrays in seconds, without
re-simulating. Figures 1 and 5 are restyled by `published_sources/recolor_figure1.py` and
`published_sources/build_figure5.py`; see [`scripts/published_sources/README.md`](../scripts/published_sources/README.md).

The closed-form check that used to be Figure S1 is now panels D–F of Figure 2.

## Dependency order

Figure 2 is the only script with prerequisites. Its panels D–F plot the simulated values
from Figure 3 panel A and Figure 4 panel A against theory, with error bands that come from
independent replications:

```
figure3_figure4_heatmaps.py ──→ arrays/Fig3_scenario1_highh_A.npy ─┐
                                arrays/Fig4_scenario2_lowh_A.npy  ─┤
                                                                   ├──→ figure2_theory_validation.py
replicate_figure3A_figure4A_panels.py ──→ tables/replication_fig3A_panel.npz ─┤
                                          tables/replication_fig4A_panel.npz ─┘
```

Everything else is independent. `make figures` runs them in the right order.

## Reference arrays

`reference/arrays/` holds the eight arrays behind the published heatmaps (about 1.6 KB each).
They are committed so that anyone can verify a reproduction without first having to trust a
re-run, and so that a change in behaviour is caught rather than silently absorbed.
