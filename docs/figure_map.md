## Dependency order

Figure S1 is the only figure with prerequisites. It plots the simulated values from Figure 3
panel A against theory, with error bars that come from an independent replication:

```
figure3-4        ──→ arrays/Fig3_scenario1_highh_A.npy ─┐
                                                        ├──→ figureS1
replicate-panel  ──→ tables/replication_fig3A_panel.npz ┘
```

Everything else is independent. `correlated-traits figures` runs them in the right order.

## Supporting commands

| Command | Purpose | Output |
|---|---|---|
| `correlated-traits replicate-column` | Per-cell standard errors and z-scores for one column; also checks the closed-form R² identity against an explicit least-squares fit | `tables/replication_fig3A_column_hh2_0.6.csv` |
| `correlated-traits replicate-panel` | The same across the full grid; supplies Figure S1's error bands | `tables/replication_fig3A_panel.npz` |
| `correlated-traits verify` | Compares regenerated arrays against the reference arrays packaged with `correlated_traits` | console report, exit status |

## Reference arrays

`src/correlated_traits/reference/arrays/` holds the eight arrays behind the published
heatmaps (about 1.6 KB each). They ship inside the package rather than sitting at the
repository root, so `correlated-traits verify` works from an installed copy and from any
directory. They are committed so that anyone can verify a reproduction without first having
to trust a re-run, and so that a change in behaviour is caught rather than silently absorbed.
